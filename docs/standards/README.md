# Standards

Esta carpeta define los estándares que rigen el desarrollo del proyecto MotoTrack. Su propósito es mantener la consistencia, calidad y profesionalismo en cada aspecto del proyecto.

## Documentos

| Documento | Propósito |
|---|---|
| **DEVELOPMENT-STANDARD.md** | Define la filosofía, metodología y el flujo de trabajo del proyecto |
| **DOCUMENTATION-STANDARD.md** | Establece la organización documental y las reglas de sincronización con el código |
| **GIT-STANDARD.md** | Describe la estrategia de ramas, convención de commits y flujo Git |

Cada documento debe leerse como referencia antes de iniciar cualquier actividad en el proyecto.
