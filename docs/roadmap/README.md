# Roadmap

Esta carpeta contiene la planificación estratégica y el seguimiento del proyecto MotoTrack.

## Documentos

| Documento | Diferencia |
|---|---|
| **ROADMAP.md** | Define hacia dónde va el proyecto: visión, hitos y evolución a largo plazo |
| **BACKLOG.md** | Organiza el trabajo pendiente: tareas priorizadas, funcionalidades y mejoras |
| **CHANGELOG.md** | Documenta lo que ya se entregó: versiones, cambios y fechas |

ROADMAP mira al futuro, BACKLOG ordena el presente, CHANGELOG registra el pasado.
