# Modelo C4

Esta carpeta contiene la documentación arquitectónica de MotoTrack utilizando el Modelo C4. Su objetivo es facilitar la comprensión de la arquitectura del sistema sin necesidad de revisar el código fuente.

## Documentos

| Documento | Propósito |
|---|---|
| **Nivel-1-Contexto.md** | Describe el contexto general del sistema, los actores que lo utilizan y las relaciones con sistemas externos |
| **Nivel-2-Contenedores.md** | Muestra los contenedores principales del sistema, sus responsabilidades y cómo se comunican entre sí |
| **Nivel-3-Componentes.md** | Desglosa los componentes internos del contenedor principal y las relaciones entre ellos |

## Alcance

Esta documentación representa únicamente la arquitectura implementada actualmente en MotoTrack. Los diagramas evolucionan junto con el código y no documentan funcionalidades futuras.

## Orden recomendado de lectura

1. Nivel 1 – Contexto
2. Nivel 2 – Contenedores
3. Nivel 3 – Componentes
