# MotoTrack — Presentation Templates

Este directorio está reservado para presentaciones institucionales con la identidad visual oficial de MotoTrack.

## Uso

1. Copiar la plantilla desde aquí antes de editar.
2. Utilizar exclusivamente los colores definidos en `BRAND_GUIDELINES.md`.
3. Los assets gráficos (logotipo, isotipo) deben referenciar `branding/logo/`.
4. No modificar la proporción ni el color del logotipo.

## Recursos

- Logotipo: `branding/logo/mototrack-logo.svg`
- Isotipo: `branding/logo/mototrack-isotype.svg`
- Guías de uso: `branding/BRAND_GUIDELINES.md`

## Formato recomendado

Se aceptan presentaciones en formato `.pptx` (Microsoft PowerPoint) o `.key` (Apple Keynote). El archivo maestro debe mantenerse en este directorio.
