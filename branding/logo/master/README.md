# MotoTrack Brand Assets — Master Source

This directory contains the single editable master source file for all MotoTrack brand assets.

## Source file

- `mototrack-brand-assets.ai` — Adobe Illustrator file

## Workflow

1. All edits must be made to the master file (`mototrack-brand-assets.ai`).
2. After editing, **export** the modified assets to `branding/logo/` subdirectories.
3. Never edit exported assets directly. The master file is the only source of truth.

## Requirements

- **Software**: Adobe Illustrator 2022+
- **Artboard sizes**: as specified in the destination column
- **Color space**: RGB
- **Resolution**: 300 DPI for print derivatives, 96 DPI for screen
